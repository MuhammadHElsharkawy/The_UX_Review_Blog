# The UX Review Blog

A modern, responsive UX and design blog website focused on sharing insights, articles, trends, and resources for designers and creative professionals.

The project features a bold, expressive visual style with responsive layouts, article sections, author profiles, community content, and a newsletter subscription area.

## ✨ Features

* 🎨 Bold and modern UX-focused design
* 📱 Fully responsive layout for desktop, tablet, and mobile
* 🧭 Responsive navigation with mobile side menu
* 📰 Latest articles section
* 🔥 Trending articles section
* 🏷️ Article categories
* 👨‍🎨 Authors section
* 💬 Community and testimonials section
* 📧 Newsletter subscription section
* 🔗 Smooth navigation between page sections
* ⭐ Font Awesome icons
* 🖼️ Local image assets
* 📐 Responsive layouts using CSS media queries

## 🛠️ Technologies

* **HTML5** — Semantic page structure
* **CSS3** — Styling, layouts, animations, and responsive design
* **JavaScript** — Interactive navigation functionality
* **Font Awesome** — Icons
* **Google Fonts** — Custom typography

## 🎨 Design

The website uses a bold, editorial-inspired visual style designed around the UX/design community.

The interface combines:

* Strong typography
* High-contrast colors
* Bold borders and shadows
* Card-based content sections
* Responsive layouts
* Clear visual hierarchy
* Playful design elements

The goal was to create a website that feels like a creative design publication rather than a traditional blog.

## 📱 Responsive Design

The website is designed to work across different screen sizes.

Responsive behavior includes:

* Desktop navigation
* Mobile navigation menu
* Flexible article grids
* Responsive typography
* Adaptive spacing and layouts
* Mobile-friendly content sections

CSS media queries are used to adapt the interface for smaller screens.

## 🚀 Getting Started

Since this is a frontend-only project, no backend or database setup is required.

### 1. Clone the repository

```bash
git clone https://github.com/MuhammadHElsharkawy/The_UX_Review_Blog
```

### 2. Navigate to the project

```bash
cd The_UX_Review_Blog
```

### 3. Run the project

You can open `index.html` directly in your browser.

For a better development experience, you can also use a local development server such as **VS Code Live Server**.

## 🖥️ Usage

Open the website and explore the different sections:

* Home
* Latest Articles
* Authors
* Community
* Newsletter

The navigation allows users to move between the different sections of the page, while the mobile navigation provides a dedicated menu for smaller screens.
